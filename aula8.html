O que eu aprendi

1. As três formas de usar JavaScript

Aprendi que o JavaScript pode ser utilizado de forma externa, interna ou diretamente em uma linha do HTML. Para um programa com aproximadamente 200 linhas que será utilizado em várias páginas, escolheria um arquivo externo, pois ele facilita a organização, a manutenção e o reaproveitamento do código. Essa organização é semelhante ao CSS, que também pode ficar em um arquivo separado para ser utilizado em várias páginas.

2. Repetição e criação de componentes

No jogo da velha, o componente Square foi utilizado para criar os nove quadrados sem precisar repetir todo o código de cada botão. No meu catálogo.html, o que se repete são os cartões dos produtos. Eu criaria um componente chamado Produto, recebendo propriedades como nome, preço e descrição, para apresentar cada produto de maneira organizada e reutilizar a mesma estrutura.

3. Propriedades e estado

No componente Produto, a propriedade nome recebe o nome do produto que será exibido. Já o estado rotulo controla o texto do botão, começando com "Adicionar" e mudando para "No carrinho" após o clique. Quando cliquei em um produto, os outros não mudaram porque cada componente possui seu próprio estado independente. Um exemplo real é o Açaí médio, que aparece no catálogo da AgroFeira.

4. Decisão sobre a estilização

Não realizei a Atividade 6, então não tinha uma decisão anterior registrada sobre a forma de estilização. Para esta atividade, escolhi utilizar CSS próprio, pois consigo controlar melhor as cores, os espaçamentos e a aparência do site. Depois de trabalhar com os componentes React, minha escolha continua sendo o CSS próprio, porque observei que também é possível aplicar estilos aos componentes sem depender de um framework.
